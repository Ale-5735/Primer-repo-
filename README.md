# ⚡ Vibe Coding con React | Página de Bienvenida del Curso

Bienvenido al repositorio oficial del curso **Vibe Coding con React**. Esta aplicación web interactiva sirve como portal de bienvenida, temario interactivo y entorno de experimentación inicial para los estudiantes del curso.

---

## 🌟 Características Principales

1. **Hero & Filosofía Vibe**:
   - Introducción interactiva al paradigma del *Vibe Coding* (desarrollo asistido por IA + React 19).
   - Conceptos clave: Prompt-to-Component, Vite HMR, orquestación y criterio arquitectónico.

2. **Vibe Playground (Simulador en Vivo)**:
   - 4 componentes interactivos demostrativos (Tarjeta Neón, Barra de Reacciones, Selector Dinámico de Colores, Generador de Ideas de Proyecto).
   - Visualizador de código React 19 generado con botón de copiado rápido al portapapeles.
   - Evaluador interactivo de prompts personalizados.

3. **Temario Completo del Curso**:
   - 5 módulos estructurados (Fundamentos, React 19 Core, UI & Estilos, Debugging Asistido por IA, Proyecto Final).
   - Despliegue de contenidos con acordeón interactivo y mini-retos prácticos.

4. **Checklist de Bienvenida al Alumno**:
   - Sistema de seguimiento de tareas de onboarding con barra de progreso reactiva y feedback de felicitación.

5. **Vibrómetro / Gamificación**:
   - Medidor de energía vibe con niveles dinámicos, contador de impulsos y consejos diarios para desarrolladores.

6. **Selector de Temas Visuales**:
   - 4 estilos visuales integrados: `Cyber Neon` (predeterminado), `Sunset Glow`, `Matrix Emerald` y `Minimal Slate`.

---

## 🚀 Inicio Rápido

Para ejecutar el proyecto en tu entorno local:

```bash
# 1. Instalar dependencias (si aún no están instaladas)
npm install

# 2. Iniciar el servidor de desarrollo en Vite
npm run dev

# 3. Compilar para producción
npm run build

# 4. Validar reglas de estilo y sintaxis
npm run lint
```
